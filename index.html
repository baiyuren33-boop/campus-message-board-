Supabase 云数据库集成 (提分项)

Campus Hub 默认工作在 LocalStorage 本地存储模式。配置您的 Supabase 服务后，即可将数据同步至云端，实现多端留言同步与共享！

👉 Supabase 快速连接指南

1. 在 Supabase.com 注册并创建一个新项目。
2. 创建一个名为 `posts` 的表。表结构需包含：
id (int8 / auto-increment), nickname (text), title (text), content (text), category (text), upvotes (int4), replies (jsonb / default: []), tags (jsonb / default: []), created_at (timestampz)
3. 启用表的 Row Level Security (RLS) 并允许匿名 Public Read/Write。
4. 将项目 URL 和 API Anon Key 填入上方并提交。
